FrostWeather.com

The Frost launch website: app preview and sample Rooms discussions.
Static HTML, CSS and JavaScript. No build step required.

Publish main / (root) with GitHub Pages. Configure frostweather.com in Pages settings.

Run locally with: python3 -m http.server 8765

See CREDITS.txt and assets/*-OFL.txt for asset credits and font licenses.
Rooms is a clearly labeled preview; live accounts and conversations are not connected yet.
