Frostweather.com

A responsive product introduction with a crafted interactive Panes app mockup, an illustrative Rooms conversation preview, and an email early-access contact.

Static HTML, CSS, and JavaScript. No build step, analytics, signup database, external runtime, or live weather requests. All fonts and graphics are local. Existing GitHub Pages CNAME and .nojekyll are retained; no new hosting registration is needed.

Local preview: python3 -m http.server 8765
Production destination: existing GitHub Pages main / (root), frostweather.com.
Publish by committing to main; GitHub Pages deploys the repository root.

Panes: native range keyboard/touch interaction, time presets, interpolated temperature, upright hour markers, and sun position synchronized to illustrative light. Mobile places the scrubber immediately below the dial.
Rooms — Unfolding: four fictional nine-moment stories move through The forecast, The shift, and Right outside. Each chapter contains three chronological comments; chapter buttons jump to its first comment. Only one incoming comment appears at a time. Next moment advances, and Replay story returns to the morning forecast at the end. Automatic moments arrive every six seconds only when the comment area is substantially visible and the document is active. Pause/resume and reduced-motion defaults are preserved. The comment area reserves space for the longest text on small screens.

Full-width archival photos are unobstructed and retain natural colors. Discreet event captions and linked author/source credits sit underneath. Photos depict separate historical events, not the fictional conversations. The styling follows the user-approved Unfolding mockup.

All temperatures, sky conditions, Room participants, and messages shown are illustrative, not live data or official reports. Frost for iPhone and Mac is in development; web posting is forthcoming.

See CREDITS.txt and assets/*-OFL.txt for asset credits and font licenses. Older screenshots and storm studies remain in assets but are not used by this page.

Brand: A new perspective on weather. Main introduction: Meet Frost. Rooms: Be there. As it unfolds.
Identity: approved sun dial icon, Geist 500 frost wordmark with raised 24-hour degree ring, and assets/palette.json.
